# StableNaira brand assets

Logo files and other brand assets for **StableNaira (SNR)** — the Naira-pegged
stablecoin issued by SMC DAO.

`snr-logo-512.png` — 512×512 PNG logo. Referenced by the SNR jetton's
TEP-64 on-chain metadata on TON mainnet (`StableNairaJettonMaster` at
`EQDuSCdKmIv2Uua6042I_69Ne4rIFPkR-_CVObYCuAmZfNqK`), so it must remain
addressable at `https://raw.githubusercontent.com/stablenaira/branding/main/snr-logo-512.png`
(the URL is baked into the jetton's immutable init data — changing it
requires a `set_code` upgrade).
